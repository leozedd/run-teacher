# 英语教练

安卓英语口语练习 App。选一个场景，按住说话，AI 教练跟你对答。
识别和断句在手机本地运行，教练回复通过设置中的模型服务生成。

本仓库用于分发安装包，不含源码。

## 安装

到 [最新 Release](https://github.com/leozedd/run-teacher/releases/latest) 下载 arm64 APK，在手机上打开安装。

- 首次启动按页面提示下载语音模型；升级安装保留已下载模型。
- v1.0.5 系列可以直接覆盖升级到 v1.1.0，保留设置和模型。
- v1.0.4 及更早版本使用旧签名，需要先卸载再安装；卸载会清除旧数据。
- 安装后在「设置 → 模型服务」配置 API 地址、模型、密钥和对应协议。

## 使用

- **场景对话**：选择场景，按住按钮说英文，松手后教练回复并朗读。
  支持剧本、引导、自由三档支架，以及字幕切换和复听。
- **重复练习**：说过话后，从练习页右上角进入，选择自己的一段原话，按
  80 → 60 → 40 秒重讲三遍。说完可提前停止，到时自动停录；每遍查看自己
  相较上一遍的估算语速和停顿变化，三遍后结束。
- **记录回看**：在「记录」页回看本次对话与重复练习结果。目前记录仅在本次
  运行期间保留，关闭应用后清空；跨重启保存和复习、复盘将在后续阶段接入。

没听到说话或朗读声音异常时，进入「设置 → 语音自检」分段检查。
