# 英语教练

安卓英语口语练习 App。选一个场景，按住说话，AI 教练跟你对答。
识别和断句在手机本地跑，只有教练的回复走云端模型。

本仓库只放安装包，不含源码。

## 安装

到 [Releases](../../releases) 下载 apk，手机上点开装。

- 只支持 arm64
- 首次启动白屏十几秒，在解包本地语音模型
- 装完到「设置 → 模型服务」填一个 API Key，OpenAI 兼容的服务都行

## 用法

选场景 → 按住按钮说英文 → 松手 → 教练回一句读出来，旁边给中文提示和候选说法。
支架分剧本 / 引导 / 自由三档。

没听到你说话、或者读出来的声音不对，进「设置 → 语音自检」。
