# 英语教练（run-teacher）

安卓端的英语听说练习 App：按住说话，AI 教练在具体场景里跟你对话。
语音识别与断句**跑在手机本地**（sherpa-onnx + SenseVoice），只有教练的回复走云端大模型。

> 本仓库只发布安装包，源码不在这里。

## 下载安装

到 [Releases](../../releases) 下载 `.apk`，在手机上点开安装
（系统会问「是否允许安装外部来源应用」，允许即可）。

- 只支持 **arm64** 手机（绝大多数 2019 年后的机型都是）。
- 安装包 197 MB，其中 228 MB 是解包后的端侧语音模型——**首次启动会白屏十几秒**
  （在把模型落盘），不是卡死，等一下就好。
- 装完先进「设置 → 模型服务」填一个 API Key（DeepSeek / 智谱 / OpenAI 等
  任何 OpenAI 兼容的服务都行），否则教练的回复走本地模板。

## 它怎么用

1. 练习页顶上挑一个场景（咖啡店点单、订餐厅……），教练会先开口；
2. **按住**底下那个按钮说英文，说完松手；
3. 教练回一句并读出来，旁边给中文提示和几条可以照着说的候选；
4. 支架分三档（剧本 / 引导 / 自由），连着几轮顺畅或卡住时会问你要不要换档。

没有分数、没有排行、没有徽章——反馈只讲这一轮比上一轮进步在哪，以及下一句可以怎么说。

## 出问题先跑自检

「按住说话没反应」「读出来的声音不对」有好几种原因，手机上看不到日志。
进 **设置 →「出问题时」→ 语音自检**：

- **测说话**：录 3 秒，把 权限 / 采到的声音 / 断句 / 识别 四段拆开各报各的；
- **测朗读**：报系统朗读引擎和实际生效的英文语音（有些国行机器只装了中文语音）；
- **试听一句**：用当前语速直接听。
